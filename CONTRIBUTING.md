# Contributing to QAPulseSK-assert

Thank you for contributing!

## Getting Started

```bash
git clone https://github.com/QAPulse-by-SK/QAPulseSK-assert.git
cd QAPulseSK-assert
npm install
npm run build
npm test
```

## PR Guidelines

- One feature or fix per PR
- TypeScript strict mode
- Update README if adding new assertions
- PRs reviewed within 48 hours
